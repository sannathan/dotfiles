# Instruções globais (todas as sessões do Copilot CLI)

- Responda em português do Brasil.
- Ambiente: Windows + PowerShell 7 (pwsh). Use caminhos com `\`.
- Não execute comandos de terminal: gere os comandos e deixe o usuário rodar. Edições de arquivo via ferramentas são permitidas.
- Dotfiles são gerenciados com chezmoi (`~\.local\share\chezmoi`): altere a fonte no chezmoi, não o arquivo de destino.
